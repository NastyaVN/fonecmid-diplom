# Дипломный проект профессии «1C-программист: с нуля до middle»
 
## ИНСТРУКЦИЯ ПО НАЧАЛЬНОЙ НАСТРОЙКЕ

### Настройки пользователей и прав

Создайте для сотрудников – «пользователей», назначьте соответствующий должности профиль группы доступа.
Бухгалтер ИТ-Фирмы (создание реализаций товаров услуг на основании документов обслуживание клиентов)
Кадровик расчетчик (кадровый учет и расчет зарплаты)
Менеджер (создание заявки документа обслуживание клиента)
Специалист (редактирование документа обслуживание клиента)

------

### Обслуживание клиентов
####	Группа и Бот в Телеграм
Для отправки уведомлений специалистам необходимо создать группу и бота в Телеграм.
Оповещения отсылаются в группу автоматически при создании нового документа «Обслуживание клиента», а также при изменении даты и ФИО специалиста.
Заполните константу «Токен управления телеграм-ботом» - токеном созданного бота.
Заполните константу «Идентификатор группы для оповещения» - идентификатором группы телеграм.
####	Обслуживание клиентов

Перед созданием заказа на обслуживание клиента заполните константу «Номенклатура абонентская плата» - создайте номенклатуру «абонентская плата» в справочнике «Номенклатура», константу «Номенклатура работы специалиста» - создайте номенклатуру «работы специалиста» в справочнике «Номенклатура».

При отсутствии этих констант будет невозможно выполнить автозаполнение данными документа реализация товаров услуг на основе данных документа обслуживание клиента.

Для подсчета суммы, выставляемой клиенту у контрагента необходимо выбрать вид договора «Абонентское обслуживание» и заполнить срок действия договора, стоимость ежемесячной абонентской платы и стоимость часа работы специалиста по договору.

Для создания актов для клиентов по договорам с абонентским обслуживанием 
бухгалтер ит-фирмы может воспользоваться обработкой в сервисе «массовое создание актов». Период должен быть выбран предыдущий месяц.

### Расчет управленческой зарплаты
Перед началом работы

В разделе «Зарплата и кадры
Необходимо заполнить справочник «Физические лица» данными о сотрудниках с указанием подразделения «административный персонал» или «специалисты»

В справочнике «Графики работы» 
- заведите в справочник необходимый график работы – например «Пятидневка»

- воспользуйтесь сервисной обработкой «заполнение графика» для заполнения данных графика на выбранный период.

- выберите вид графика работы – например «пятидневка».
Выберите период – например с 01.01.2026 по 31.12.2026, 
назначьте «выходные дни» - например 6,7 (суббота, воскресенье) 
Нажмите заполнить.

Для расчета отпускных необходимо заполнить графика «Отпуск» с выходными «0».


В регистре «Условия оплаты сотрудникам» необходимо назначить оклад для каждого сотрудника.

Если сотрудник получает процент от выполненных работ клиенту назначьте сумму процента в специальном поле. Для подтверждения, что процент назначен установите галочку в ячейке «процент назначен».

При не установленном проценте для специалиста не будет проводиться документ «обслуживание клиенту».

В документе «начисление зарплаты» для расчета отпускных необходимо выбирать график «отпуск».

### ТЕСТИРОВАНИЕ

Установка Vanessa Automation: Скачайте последнюю версию Vanessa Automation с GitHub и распакуйте архив в удобное место. В архиве вы найдете файл vanessa-automation.epf — это основная обработка фреймворка. Также существует версия в виде расширения, если ваша конфигурация находится во Фреш.

Запуск 1С в режиме TESTMANAGER: Запустите 1С:Предприятие с ключом /TESTMANAGER. Это необходимо для работы Vanessa Automation в качестве менеджера тестирования. Вы можете добавить этот ключ в параметры запуска информационной базы через контекстное меню "Изменить"

Открытие обработки Vanessa Automation: В запущенном экземпляре 1С откройте файл vanessa-automation.epf. 

Вы увидите главное окно фреймворка.

Подключение клиента тестирования: На вкладке "Клиенты тестирования" нажмите кнопку "Подключить выбранного клиента тестирования". В открывшемся окне выберите тип клиента (тонкий, толстый, веб), укажите путь к информационной базе, которую будете тестировать, и при необходимости дополнительные параметры запуска. Vanessa Automation автоматически запустит второй экземпляр 1С в режиме TESTCLIENT. Убедитесь, что в настройках клиента тестирования разрешен внешнее управление.
